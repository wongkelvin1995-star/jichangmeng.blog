这是机场梦使用说明。机场梦是一个小小的资料站：我们把机场服务商的套餐、流量规则、客户端要求和还没确认的地方整理在一起，让你在付款前先看清楚。下面按“找到品牌、看懂卡片、读资料页、去服务商页面前再核对”的顺序，配上本站截图，说明每一处怎么看。

我们不做第三方机场排行榜，也不替你选一家“最好的”。目录里的顺序是我们的展示顺序；价格、流量和规则都标着来源和日期，没核实的地方会直接写出来。

## 用机场梦挑选的四个步骤

### 第 1 步：在目录里缩小范围

打开机场资料目录，先用筛选栏缩小范围：可以输入品牌名或别名（例如 FLY V、V2云），按资料列出的地区筛选，按付款方式只看有月付、年付或一次性流量包的品牌，再选择按编辑顺序、最低月付或年付总价排序。

按价格排序时，没有可比较报价的品牌会排在后面。这不代表它更贵，只是现有资料不足以比较。

### 第 2 步：看懂一张卡片

每家服务商在目录里是一张卡片，从上到下依次是标识、编辑顺序和状态标签、最低月付、资料要点、地区和节点、客户端提示、优惠码，最后是展开报价和推广入口。

| 卡片上的内容 | 是什么意思 |
|---|---|
| 编辑顺序 | 我们的展示顺序，不是性能、销量或口碑排名 |
| 状态标签 | 资料核对到了哪一步，例如“官网待核验”“有来源差异”“运营状态待核” |
| 最低月付 | 已整理报价里可以比较的最低月付，没有代入优惠码；月付报价有冲突时不显示 |
| 资料要点 | 从资料里摘出的两三条特点，不是我们的实测结论 |
| 客户端提示 | 资料写明暂停或不支持第三方订阅时，卡片上会单独提示 |
| 优惠码与“复制” | 站长确认的规则：8 折、每位用户限用一次、一次性流量包不参与，结算时确认 |
| 查看全部报价 | 展开这家的全部报价，冲突、存疑和定制的档位都有标记 |
| 查看服务与套餐 | 推广链接，会进入服务商的页面 |

### 第 3 步：打开资料页，读套餐表和待确认事项

有资料评析的品牌，卡片上的名称可以点开，进入品牌资料页。页面里最常用的是套餐表：每一行是一条报价，分开写付款周期、一次付款的标价、流量额度和流量周期，最后一列是资料状态。季付、年付下面的“算术折合”只是除出来的参考，不是实际的月付售价；标着“资料标价存疑”的，是资料里看起来算错的价格，我们保留原标价，请在结算时确认。

资料页里还有这些部分：

- **优惠码与邀请码**：优惠码规则和资料记录的其他优惠码；邀请码是推广链接里的注册参数，和优惠码分开写。
- **节点与线路**：资料写的地区、节点数和线路说明，数字对不上时会列出疑点。
- **客户端与订阅**：上面是本站建议，下面是资料记录的服务商说明。
- **流媒体、AI 声明与测试记录**：“支持某某服务”是服务商的声明；测试记录单独列出时间和条件，不写成机场梦实测。
- **客服、退款与试用**：资料写到的客服渠道和规则；没写的地方标“资料未写”，不代表没有。
- **来源差异与待确认事项、资料来源与更新记录**：说法不一致的地方、资料日期和来源都集中在这里。

### 第 4 步：去服务商页面前，再核对一次

“查看服务与套餐”是推广链接，你通过它注册或购买，我们可能获得佣金，但不会另外向你收费。最终金额、优惠码能不能用、能不能退款，以服务商结算页为准。付款前，把要买的套餐、付款周期和流量再对一遍。推广关系的说明见[推广与价格说明](/disclosure/)。

## 我们怎样维护这些资料

- 文章和资料页顶部写着最后更新日期，价格旁边写着资料日期和来源类型。我们不用构建时间冒充“每日更新”。
- 拿到新资料时，和已有资料一致的记为复核一致；说法不同的保留原来的值，把新数值列为候选并标出冲突。
- 没有实测的项目，不写速度和稳定性结论；第三方测试注明来源，不写成本站实测。
- 资料状态的完整说明见[编辑方法](/editorial-policy/)。

## 常见问题

### 编辑顺序是排行榜吗？

不是。它是我们的展示顺序，不代表统一测评、销量或绝对排名，我们也不做第三方机场排行榜。

### 为什么有的品牌没有资料页？

只有具备这家独有的资料和分析时，我们才写资料页；其他品牌先放在目录卡片里，不用模板拼出内容空洞的页面。

### 卡片上的价格就是我要付的钱吗？

不一定。那是整理时的报价记录，没有代入优惠码；最终金额以服务商结算页为准。

### 在机场梦能直接买套餐吗？

不能。我们不提供网络接入，也不代收费用；购买、售后和退款都在服务商那里完成。
