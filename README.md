## 我们怎么整理资料

- 每条价格都写明来源和日期；不虚构价格，也不把最低价直接当成最好的选择。
- 事实、编辑分析和还没确认的部分分开写；没有实测，就不写速度和稳定性结论。
- 不做第三方机场排行榜。推荐顺序是编辑展示顺序，不是统一测评、销量或排名。
- 部分入口含推广链接，通过本站注册或购买可能使本站获得佣金，本站不另收费用。详见[推广与价格说明](https://jichangmeng.blog/disclosure/)。
